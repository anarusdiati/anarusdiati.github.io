## Overview

This project predicts whether an online shopping session will end in a purchase, using
behavioral and session-level features. Understanding purchase intention helps businesses
prioritize marketing spend and personalize the shopping experience.

## Objective

Build a classifier that flags high-intent sessions so they can be targeted with the right
offer at the right time.

## Approach

- Explored and cleaned the session data, then engineered behavioral features
- Handled class imbalance between purchasing and non-purchasing sessions
- Trained and compared several classification models, tuning for the best trade-off
  between precision and recall

## Tech Stack

- Python (pandas, NumPy)
- scikit-learn
- Matplotlib / Seaborn for visualization

## Outcome

The model highlights the behavioral signals most associated with purchase intent.
