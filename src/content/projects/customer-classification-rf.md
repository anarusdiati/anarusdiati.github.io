## Overview

Building on the customer segmentation work, this project trains a supervised model to assign
new customers to the segments discovered through clustering — turning a one-time analysis
into a reusable prediction tool.

## Objective

Predict the segment of a new customer automatically, without re-running clustering.

## Approach

- Used cluster labels as the target variable
- Trained a Random Forest classifier on customer features
- Evaluated performance and inspected feature importance

## Tech Stack

- Python
- scikit-learn
- pandas, Matplotlib

## Outcome

A model that classifies incoming customers into the existing segments.
